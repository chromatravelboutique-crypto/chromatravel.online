2. Integración con *fenixtra-20*:
   - Todos los enlaces a Amazon deben llevar el parámetro tag=fenixtra-20.
   - Usa el script oficial de Amazon Widgets (//z-na.amazon-adsystem.com/widgets/onejs?MarketPlace=US) para cargas enriquecidas donde sea posible.
   - Además genera enlaces directos si el widget no es posible (ej.: https://www.amazon.com/dp/{ASIN}?tag=fenixtra-20).

3. Productos ad-hoc ya poblados:
   - Crea un set inicial de 8 productos (categorías: maletas, backpacks, adaptadores, powerbanks, travel pillows, neceser, cámara compacta, botellas térmicas).

   - Ejemplo de enlaces de búsqueda si no hay ASIN: https://www.amazon.com/s?k=travel+backpack&tag=fenixtra-20 — mostrar como resultado alternativo.

4. Admin UI:
   - Crear /admin/products (protegida por contraseña simple en front-end o por token env var).
   - Permite: Añadir producto mediante ASIN o URL (el sistema extrae título e imagen automáticamente si es posible), editar título/descripcion/enlace, eliminar producto y marcar categoría.
   - Guardar la lista en un JSON local (/data/affiliate-products.json) o en localStorage (documentar cómo cambiar a DB).

5. Visual y UX:
   - Galería responsive con cards: imagen, título, precio (si disponible), rating (opcional), botón afiliado.

   - Lazy-loading de imágenes y optimización para móvil.

6. Tracking y privacidad:
   - Asegura que los clicks afiliados se registren en consola (o en log simple) para pruebas.
   - Incluye un banner de consentimiento de cookies (light) que permita bloquear la carga del widget de Amazon hasta que el usuario acepte (cumplimiento básico GDPR/privacidad).

7. SEO y rendimiento:

   - Añade metatags OpenGraph para la página de recomendaciones.

8. Documentación y entrega:

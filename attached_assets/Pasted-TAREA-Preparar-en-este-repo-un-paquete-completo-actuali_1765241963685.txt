PROVISION.SH (lo que debe hacer exactamente)

* apt update && apt upgrade -y
* instalar unzip, git, curl, wget, certbot, python3-certbot, postgresql-client (no server si usan RDS), mailutils (opcional)
* instalar nvm + node LTS (22.x) o apt node si prefieres
* instalar pm2 global (npm i -g pm2) opcional
* instalar docker & docker-compose-plugin (opcional) y agregar user al grupo docker
* crear usuarios y carpetas seguras:

  * /var/www/chroma (owner www-data or nobody según OLS)
  * /backups/chroma
* configurar UFW (allow ssh, http, https) y fail2ban basic
* instrucciones para obtener password panel OpenLiteSpeed (si aplicable)

DEPLOY.SH (pasos exactos y seguros)

* detener servicio pm2 chroma-app si existe
* descomprimir chroma-deploy.zip en /var/www/chroma (hacer backup previo si existe)
* copiar env.example -> .env (no sobrescribir si ya existe, preguntar)
* si Node app:

  * cd /var/www/chroma && npm ci --production && npm run build
  * pm2 start ecosystem.config.js OR pm2 start npm --name chroma-app -- start -- -p 3001
  * pm2 save
* si static:

  * asegurar index.html en /var/www/chroma
* si Docker:

  * docker compose pull && docker compose up -d --build
* registrar logs output y exit code; si falla, rollback to previous tar.gz (script debe crear backup tar.gz antes de sobrescribir)

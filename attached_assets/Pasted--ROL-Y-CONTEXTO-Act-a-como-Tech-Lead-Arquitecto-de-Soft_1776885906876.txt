# REGLAS DE IMPLEMENTACIÓN
- Stack: Next.js 14 (App Router) + TypeScript + Tailwind + PostgreSQL + Prisma/Drizzle + Redis.
- Validación: Zod en inputs y payloads.
- Pagos: Clip maneja tarjeta (PCI-DSS cubierto). Tu backend solo almacena `payment_id`, `status`, `amount`.
- Webhooks: Verificar firma, reintentos con exponential backoff, idempotencia por `idempotency_key`.
- Iframe: Respetar CSP de Facebook/Instagram. Usar `sandbox="allow-scripts allow-same-origin"` si es necesario.
- CI/CD: GitHub Actions para test, lint, build, deploy a staging/production.
- Documentación: `README.md` con variables de entorno, scripts de instalación, diagrama ERD, checklist de despliegue.

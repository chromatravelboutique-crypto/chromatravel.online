TAREA: Usar la paleta de Chroma, generar favicon multicolor y configurar las fuentes recomendadas. Entregar archivos listos para web y ejemplo de integración en HTML/CSS y Tailwind.

1) PALETA (usar exactamente estos hex)
--chroma-emerald: #00A878;
--chroma-magenta:  #9B1B9D;
--chroma-gold:     #FFC72C;
--chroma-indigo:   #003A70;
--chroma-coral:    #FF4632;
--chroma-gray:     #2A2A2A;

2) FONTS (Google Fonts)
- Heading: Poppins (weights 500, 700)
- Body: Inter (weights 300, 400, 600)

Incluir en <head> (HTML):
<link rel="preconnect" href="https://fonts.googleapis.com  ">
<link rel="preconnect" href="https://fonts.gstatic.com  " crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter  :wght@300;400;600&family=Poppins:wght@500;700&display=swap" rel="stylesheet">

3) ARCHIVOS A CREAR (entregar en /public o /static)
- /public/favicon.svg        -> SVG vector del favicon (multicolor, mano blanca)
- /public/favicon-16.png
- /public/favicon-32.png
- /public/apple-touch-icon.png (180x180)
- /public/site.webmanifest (con iconos)
- /src/styles/colors.css     -> CSS con variables de color
- /src/styles/fonts.css      -> CSS con reglas de fuente y clases utilitarias
- /tailwind.config.js        -> configuración con colores añadidos

4) INSTRUCCIONES PARA EL FAVICON (especificación exacta)
- Tamaño base SVG: 128x128 viewBox
- Fondo: círculo dividido en 5 sectores (arcos) en sentido horario con los 5 colores de la paleta (emerald → magenta → gold → indigo → coral).
- Centro: silueta de **mano** simple (mano estilizada, sin detalles, relleno blanco) centrada y escalada para cubrir ~56% del diámetro.
- Bordes limpios, sin stroke negro.
- Exportar en SVG y generar PNGs en 16x16 y 32x32 y 180x180 y 512x512.

PSEUDOCOMANDOS para generar PNGs (en Replit/Node):
# instalar sharp
npm install sharp
# convertir
node -e "const sharp = require('sharp'); sharp('public/favicon.svg').resize(16).png().toFile('public/favicon-16.png')"
